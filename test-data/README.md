# Datos de Prueba

Colocar aquí los PDFs y Excels de prueba de la BUAP:

- `programacion_academica.pdf` — PDF oficial de programación académica (para importar materias en MS-2)
- `directorio_docentes.pdf` — PDF del directorio institucional de docentes (para importar en MS-3)
- `lista_alumnos_ejemplo.xlsx` — Excel de ejemplo con lista de alumnos (para importar en MS-3)

> ⚠️ NO subir datos reales de alumnos/docentes al repositorio público.
> Usar datos ficticios para las pruebas.
